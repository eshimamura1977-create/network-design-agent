# ネットワーク設計支援 ブラウザー版

Python・Git・EXE・アプリサーバーを使わずに、ブラウザー内で資料を整理し、設計ドラフトを出力する版です。Microsoft 365 Copilotは別の画面で操作し、依頼文とJSON回答をコピーして受け渡します。本アプリにAIモデルは内蔵していません。

## 起動

1. `network-design-browser.zip`をダウンロードします。
2. ZIPを右クリックし「すべて展開」します。ZIP内のHTMLを直接開かないでください。
3. 展開先の`network-design-browser/index.html`をEdgeまたはChromeで開きます。
4. 初回は「操作確認用サンプル」→「成果物ZIPを作成」→「成果物ZIPをダウンロード」を試します。

フォルダー内のJS・CSS・vendorをHTMLと一緒に保持してください。外部CDNからの取得、アプリからの外部通信、サーバーへのファイル送信は行いません。SharePointやファイルサーバーはZIPの保管・配布先として利用できますが、そこからプレビューせず、PCへダウンロード・展開して開いてください。

社内ポリシーでローカルHTMLやJavaScriptが禁止されている場合、この方式も利用できません。制限を解除する手順は含めていません。

## 実案件で使う順番

1. 案件名を入力し、要件定義書・現行資料を取り込みます。
2. 「要件候補を抽出」を押し、候補の内容と出典を確認します。不要な行は削除し、必要に応じて本文と確認状態を変更します。
3. 「設計依頼を作成」を押します。表示された依頼文を、会社で利用するM365 Copilotまたは専用エージェントへ貼り付けます。複数に分割されている場合は、同じチャットへ番号順にすべて貼り付けます。
4. Copilotが出したJSON全体をアプリの回答欄へ貼り付け、「回答を検証して取り込む」を押します。JSONファイルからの読み込みも可能です。
5. 共通設計・基本設計・下流工程・整合性レビューの4段階で、3〜4を繰り返します。
6. 「成果物ZIPを作成」→「成果物ZIPをダウンロード」で一括取得します。
7. 閉じる前に「案件を保存」で案件JSONを保存します。次回は「保存した案件を開く」で続きから再開します。

コピーが許可されないブラウザーでは依頼文が選択されるため、Ctrl+Cでコピーしてください。JSONの前後に説明文がある場合は、JSON部分だけ貼り付けます。JSONのコードブロックはそのまま扱えます。回答が途中で切れた場合は、完全なJSONをCopilotに再出力してもらってください。

入力を編集すると依頼IDとAI回答はリセットされます。比較したい場合は編集前に案件を保存してください。資料を削除しても関連要件は残り、「未解決」になります。要件候補の再抽出は一覧全体を置き換えます。

## 出力

| 種類 | 内容 |
| --- | --- |
| Word | 要件定義、基本設計、詳細設計、試験設計、移行設計、運用引継ぎ |
| Excel | 機器台帳、アドレス台帳、接続台帳、ホスト別・機種別パラメータ、試験項目、工事手順、要件対応・レビュー |
| Visio・SVG | 共通設計から作成する構成図と試験構成図 |
| Config案 | 機器ごとのレビュー用TXT。機種・OSを原文で特定できない場合は作成待ち理由のみ |
| JSON | 設計データと成果物一覧・要レビュー状態を示すmanifest |

出力はすべて要レビュー・未承認です。Configの投入機能はなく、試験結果は未実施です。引用・ID・アドレス・ポート・要件対応の機械検査は、設計内容の正しさを保証するものではありません。構成図は自動配置のため、接続が多い場合はVisioで配置を調整してください。SVGの接続IDは接続台帳と対応します。

## 入力形式と上限

- DOCX：本文と表の文字。ヘッダー、フッター、埋込オブジェクト、画像内文字は対象外。
- XLSX：シート・セルの値。数式は文字列と保存済み値を取り込み、再計算しません。日付書式など表示形式の完全再現は行いません。
- PPTX：スライドの図形文字、表、ノート。非表示スライドも明示して取り込みます。
- VSDX・VDX：ページ上の図形文字、属性、登録された接続情報。マスター継承の展開は未対応。
- TXT・MD・CSV・CFG・LOG：UTF-8、BOM付きUTF-16、Shift-JISの文字。YML/YAMLは現在直接選択できないため、規則をTXTまたはMDとして用意してください。
- 旧DOC/XLS/PPT/VSDはOfficeで新形式に保存し直してください。拡張子の変更だけでは変換できません。PDF・OCR・マクロ実行は未対応。
- 1ファイル8MB、抽出本文16万字、20ファイル、要件400件。大きすぎる場合は切り捨てず停止します。
- AI依頼は資料と要件の本文合計5万字まで。前段階を含む依頼データは26万字まで。依頼文は約9,000字ずつ分割します。
- AI回答は200万字まで、保存案件は16MBまでです。

## 保存とAI連携の範囲

アプリには自動保存や自動ログインがありません。案件JSONと成果物ZIPの設計データには、入力資料の抽出本文が含まれます。共有範囲を確認して保管してください。ブラウザーの更新・終了で未保存のデータは失われます。

M365 Copilotへのコピーは利用者自身が行います。テナントID・クライアントID・シークレットを本アプリへ設定する必要はありません。既存の専用エージェントが指定のJSON形式を返せるかは実際に確認が必要です。SharePoint上の規則や雛形の自動取得、既存Office雛形のレイアウト適用、承認済み完成品の自動確定は未実装です。

## 検証状況

2026年10月1日現在、20項目のNodeテスト、全工程ZIPの内部検査、Word・Excelの読み戻し、VSDXのXML構造を確認しました。静的HTTP配信した画面では、サンプル読込、ZIP生成完了、既存のダミーPPTX取込、要件抽出、資料削除、依頼文生成まで確認しています。

以下は未確認です：`file://`での直接起動（検証用ブラウザーの制限）、ブラウザーからのファイル保存完了（ダウンロード待ちがタイムアウト）、保存案件の画面上の再読込、追加のWord・Excel・Visio入力テスト、実際のCopilot回答、社用PCのポリシー、Word印刷レイアウト、Visioデスクトップでの表示。追加の画面検証は自動承認レビューの利用上限で停止しました。
