管理者に依頼する内容

単一テナントのアプリを登録し、「モバイルとデスクトップ アプリ」に上記URIを追加してください。Graphの次の委任権限はChat APIの必須条件です。管理者に利用範囲を確認してもらってください。

Sites.Read.All / Mail.Read / People.Read.All / OnlineMeetingTranscript.Read.All / Chat.Read / ChannelMessage.Read.All / ExternalItem.Read.All

Chat APIはプレビューです。サインインで必須のGraph権限を要求します。案件の資料は「M365 Copilotで要件を整理」を押した場合だけ送信します。Web検索は無効にしますが、Copilotの社内検索機能自体を無効化する設定ではありません。

認証情報はこのアプリのメモリ内だけに保持します。再起動後は再サインインが必要です。Microsoft全体からのサインアウトは行いません。

.env の LLM_BASE_URL と LLM_MODEL、必要に応じて LLM_API_KEY を設定して再起動してください。

外部HTTPS APIへ接続する場合は、承認された処理先に限り ALLOW_REMOTE_LLM=true を設定します。
